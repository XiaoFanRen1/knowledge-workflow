# Knowledge Workflow

This repository owns the public, project-neutral workflow and local knowledge runtime.
Use current source and focused tests. Keep user data outside the source and release tree.
Do not import personal knowledge, credentials, machine configuration, or private Git history.
The package has no dependency on a particular firmware SDK or editor.

Changes to storage, process ownership, installation, or public interfaces require failure-path tests.
Preserve existing user modifications. Never run firmware builds, flashing, or destructive device commands.
Use natural task instructions; Entry, settlement, fixed response headers, and Stop continuation are not prerequisites.
Before publishing, validate the release inventory, licenses, dependency hashes, and privacy scan.
Report implementation, isolated tests, real client usage, and external user acceptance separately.
