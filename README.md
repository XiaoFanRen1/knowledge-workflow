# Knowledge Workflow

An engineering workflow with private, local knowledge capture and retrieval.

**Development candidate: installation and external-user acceptance are not yet complete.**

The public package contains code, instructions and synthetic examples. Bring your own
knowledge: documents, indexes, feedback and model caches stay in your local data directories.
Selected evidence used in an answer is sent to your own Codex session.

Initial target: Windows 11 x64, standard CPython 3.14 and Codex. No firmware SDK is required.
The source repository must never be used as a knowledge data directory.
